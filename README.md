# 새봄 다이어리

**나의 몸, 나의 회사.** 체중 기록을 쌓으며 포근한 픽셀 사무실을 운영하는 무료 다이어트 다이어리입니다.

![새봄 카페 사무실](web/회사-미리보기.png)

## Android 설치

[Android APK 다운로드](https://github.com/glasscola/dietdiary/releases/download/v0.4.0/saebom-dietdiary-v0.4.0.apk) · [배포 안내](https://github.com/glasscola/dietdiary/releases/tag/v0.4.0)

휴대폰 브라우저에서 APK를 내려받은 뒤, **내 파일 → 다운로드**에서 파일을 눌러 설치합니다. GitHub 로그인 없이 다운로드할 수 있습니다.

- Android 8.0 이상, 최신 Android System WebView 권장.
- 화면과 코드가 APK 안에 포함되어 PC 서버나 인터넷 연결 없이 실행됩니다.
- 인터넷·카메라·위치·연락처·저장소 전체 접근 권한을 요구하지 않습니다.
- 갤럭시의 ‘알 수 없는 앱 설치’ 또는 ‘보안 위험 자동 차단’ 설정은 직접 받은 APK를 차단할 수 있습니다. APK 서명이나 GitHub 배포만으로 이 설정을 우회하지 않습니다. 본인이 이 저장소에서 받은 파일인지 확인하고 삼성 공식 설치 안내를 따르세요.
- 설정 → 백업 내려받기는 Android 파일 저장창으로, 가져오기는 파일 선택창으로 연결됩니다. PC 웹 기록을 옮기려면 JSON 백업을 가져오세요.
- 새 버전은 같은 서명 키와 더 높은 versionCode로 업데이트합니다. 앱을 삭제하면 내부 기록도 삭제될 수 있으므로 먼저 백업하세요.

## 주요 기능

- 체중 필수, 골격근량·체지방량·수면·칼로리·메모 선택 기록.
- 체중·체성분의 주간/월별/1년/전체 그래프와 별도 회사 가치 그래프.
- 일일/주간 퀘스트 추가, 요일 반복·일회성, 수정·삭제·완료 취소. 주사위 보너스 10~60%.
- 하루 영수증, 총평, 도장과 생활에 맞는 응원 문장·명언집.
- 2~4층 각 3명, 사장실·1층 면접실/미팅룸·옥상 휴게실. 직원은 엘리베이터를 타고 이동하며 외형을 유지합니다.
- 가구 31종. 구매→보관→층/자리 배치, 관리 탭의 업그레이드, 해금한 이전 스킨 선택.
- 가구 효과는 개인 자리/해당 층/모든 직원에 구분 적용. 업무 효율 합산 최대 35%.
- 매일 선배당 후 월급 정산. 회사 가치 하락 자체로 보유 골드를 회수하지 않습니다.
- 샘플 회사와 내 기록을 분리합니다. 가상 날짜 진행은 샘플에서만 가능합니다.

## 웹 실행과 검사

Node.js 20 이상이면 추가 패키지 설치 없이 실행합니다.

```sh
npm test
npm start
```

`http://127.0.0.1:4174/`에서 PC와 모바일 세로 화면을 검사합니다. 기록은 해당 기기·앱의 저장 공간에만 저장되고 자동 동기화되지 않습니다. [데이터 안내](web/privacy.html)

```sh
npm run build
```

웹 배포용 `dist/`와 Android 오프라인 자산을 생성합니다. 소스와 Android APK는 공개되어 있으며, 공개 웹사이트 자동 배포는 설정하지 않았습니다.

## Android 빌드

JDK 17, Android SDK 36과 Build Tools 35.0.0을 설치하고 `android/local.properties`에 로컬 SDK 경로를 지정합니다. Gradle Wrapper 8.14.3, Android Gradle Plugin 8.13.0을 사용합니다.

```sh
npm run build
cd android
./gradlew assembleDebug lintDebug
```

서명한 release 빌드에는 다음 환경 변수를 지정한 뒤 `assembleRelease lintRelease`를 실행합니다.

| 변수 | 용도 |
| --- | --- |
| `SAEBOM_KEYSTORE_PATH` | 로컬 키스토어 절대 경로 |
| `SAEBOM_STORE_PASSWORD` | 키스토어 비밀번호 |
| `SAEBOM_KEY_ALIAS` | 키 별칭, 기본 `saebom` |
| `SAEBOM_KEY_PASSWORD` | 키 비밀번호 |

키스토어와 비밀번호는 저장소에 포함하지 않습니다. 최초 배포 서명 키를 잃으면 기존 앱에 같은 앱으로 업데이트할 수 없으므로 따로 보관하세요. GitHub Actions는 웹 테스트와 Android debug 빌드/lint를 실행하며 release 서명 키를 사용하지 않습니다.

## 디자인과 범위

크림·갈색·세이지 팔레트, 원목·패브릭·라탄 가구, 니트 복장의 동료들과 새싹 사무실 아이콘을 직접 코드로 구성했습니다. 아이콘 원본은 `web/icon.svg`, Android 적응형 아이콘은 벡터 자산입니다. PNG 재생성은 Python/Pillow로 `scripts/create-icons.py`를 실행합니다.

현재 버전은 데모 밸런스입니다. 건강 데이터 자동 연결·계정 로그인·광고·결제·클라우드 동기화는 없습니다. 라이선스는 아직 지정하지 않았습니다.

## 0.2.0 업데이트

- 일정 분류 → 담당 부서 업무 → 확정 운영 수익. 체중 감량과 별개로 실천의 성과를 얻습니다.
- 주간 목표 횟수(1~30), 날짜별 실천, 최근 실천 취소, 오늘만 쉬기.
- 회사 화면 아래 3종 프로젝트: 실천한 날짜와 기념패를 확인하고 옥상에 전시합니다.
- 직원 상세의 담당 업무·예상 수익·능력치 역할, 영수증의 가구 추가 수익.
- 의자 위치·앉은 다리·책상 가림 순서·모니터 위치, 손 움직임과 방향 전환.
- 실제 시각의 아날로그/디지털 시계, 시간대별 창문·해와 밤하늘, 순차 출력 말풍선.

기존 기록·직원·골드·가구를 유지합니다. 업데이트 전 JSON 백업을 권장합니다. 결산된 일정은 이미 지급한 운영 수익을 보존하기 위해 취소할 수 없습니다. 현재 프로젝트는 실천 날짜 기준이며, 모든 가구의 차별화된 전용 모션과 대규모 이벤트는 포함하지 않았습니다.

## 0.3.0 개편

- 반복 안내 문구와 화면별 영문·소개 축소. 결산 상세는 펼쳐보기.
- 체중 없는 독립 일기, 계획한 휴식, 날짜 이동과 미래 일정 확인, 일기 검색, 최근 7일 회고.
- 유한한 부서 업무 분담, 운영/개선/지원 역할, 사기와 가구 효과를 실제 성과에 적용.
- 책상·시계는 수익, 컴퓨터·서가는 프로젝트, 의자·옥상은 편안함. 업그레이드 전 실제 업무 기준 차이 표시.
- 담당 직원이 수행하는 프로젝트, 다음 방향 선택, 완료 보상 영구 보관. 이전 기념품은 호환 보관.
- 결산 후 일정 수정과 당시 직원/가구 조건의 운영 수익 차액 처리. 완료 기념품과 성장 이력은 회수하지 않습니다.
- 신형 배당 완만한 증가 곡선. 기존 결산은 당시 배당 정책으로 수정합니다.
- 새 가구·프로젝트 기억·휴식·역할·동료 문답 대화, 옥상 장식 가림 수정.

이 버전은 기능 구조 개편입니다. 직원 일러스트 전체 교체, 자유 공간 편집, 관계별 장편 이야기, 월간 달력 그리드와 알림은 포함하지 않습니다. 현재 이동은 기존 엘리베이터 경로를 유지합니다. 기존 앱 삭제 없이 업데이트하고, 먼저 JSON 백업을 저장하세요.

## 0.4.0 아트 업데이트

`web/art.mjs`에서 직원과 31종 가구의 1~5레벨 외형을 새로 그립니다. 가디건·니트·셔츠·멜빵·정장, 헤어 실루엣·안경·핀·귀걸이, 원목 결·직물 봉제·쿠션·노트북 힌지/키보드·기기별 프레임·아날로그 눈금/디지털 시계·커피 머신·라탄 구조를 구체화했습니다. 건물에는 목재 바닥 이음새·벽 패널·창틀/커튼·옥상 조명·엘리베이터 표시를 반영했습니다.

건물·초상·가구 캔버스는 두 배 해상도로 렌더링하며 부드러운 크기 조절을 적용합니다. 기존 직원의 외관 식별값, 보유 가구 레벨·스킨·기록은 유지합니다. 새로운 런타임 의존성이나 외부 이미지 다운로드는 없습니다.
